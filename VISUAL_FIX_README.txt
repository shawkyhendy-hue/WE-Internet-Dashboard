WE Dashboard Visual Analytics v2

IMPORTANT:
A 404 on /visual means an older Flask server is still running on port 5000.

1. Close every old WE Dashboard CMD window (or press CTRL+C in it).
2. Copy your existing we_dashboard.db and .we_secret.key into this folder if needed.
3. Run run_dashboard.bat.
4. Confirm CMD prints: Visual Dashboard: http://127.0.0.1:5000/visual
5. Test http://127.0.0.1:5000/version
6. Open http://127.0.0.1:5000/visual or run OPEN_VISUAL_DASHBOARD.bat.
